# 8장 구성 계획 — 중앙 공공기관 경영평가

> 시범장(pilot). 이 장에서 검증하는 것: ① 연강 구조(1차시 이론·제도 / 2차시 편람 실습)가 평가 실무 장에서 작동하는가 ② 400줄 개조식 규격이 편람 실무 내용에서 성립하는가 ③ 출처 증거 게이트(모든 배점에 편람 출처 병기)가 실제로 지켜지는가.

## 장 성격·핵심 질문

- 성격: 평가 실무 (강의계획서 §3)
- 핵심 질문: 재정경제부 공공기관 경영평가는 무엇을 요구하는가?
- 세 질문 중 대응: "경영평가 지표로 만들면 어떤 장점과 왜곡이 생기는가?"

## 1차시 (이론·제도, ~55%)

1. 오늘의 질문 / 들어가며
2. 핵심 개념: 경영평가란 무엇인가 — 자율경영과 책임성의 교환, 통제장치로서의 평가
3. 제도 설명
   - 법적 근거·소관 부처: 공공기관운영법, 재정경제부, 공공기관운영위원회
   - 평가 대상: 공기업·준정부기관(88개) vs 기타공공기관(주무부처). 지정 342개와의 관계
   - 평가 유형: 산업별 구분(상장/SOC/에너지/산업진흥·서비스, 준정부 위탁/기금)
   - 평가 주체: 평가단(교수·회계사 등)
   - 평가 절차·일정: 실적보고서 → 평가 → 공운위 확정
   - 평가 범주: 경영관리 / 주요사업 / 혁신 프로젝트 3범주

## 2차시 (편람 실습·사례, ~45%)

4. 편람 읽기 실습: 유형별 배점표 읽는 법과 비교
5. 경영관리 범주 뜯어보기 (경영전략·ESG / 안전 및 책임경영·재난안전 / 재무성과관리 / 조직 운영)
6. 주요사업 범주와 PDCA 성과관리
7. 2026년 개편: 혁신 프로젝트 범주(상장 8점), 혁신 가점 5점(안전1.5/AI1.5/국정과제2), AI 두 경로
8. 실적보고서와 기관의 대응
9. 평가 결과 활용: 6등급 S~E, 성과급, 해임 건의
10. 사례·비판적 관점

## 사례 처리 방침

- 특정 기관의 실제 평가등급·성과급은 검증된 최신 출처가 없으면 단정하지 않는다(P0). 대신 **편람 배점표 읽기 자체를 사례**로 삼고, 성과급·해임 건의는 제도 메커니즘으로 설명한다.
- 실물 대조가 필요하면 ALIO(alio.go.kr) 경영공시·실적보고서를 학생 실습 과제로 연결.
