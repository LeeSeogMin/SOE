# GOTCHAS — 공기업론 강의자료 지뢰 목록

## 출처와 사실

- 본문 수치·지표 배점·부처명·법령·통계는 `content/research/ch{N}-sources.md`에서 확인된 것만 인용한다.
- 편람 인용은 연도를 밝힌다(2026년도 판). 부처명은 2026-01 개편 기준(재정경제부).
- 재무 수치는 확인 시점을 함께 남긴다. 확인 못 한 값은 "확인 필요"로 표기한다.

## 제도 정확성

- 중앙 공공기관 유형(공기업/준정부기관/기타공공기관)과 지방공기업 유형(지방공사/지방공단/직영기업)을 혼동하지 않는다.
- 중앙(재정경제부)·지방(행정안전부) 평가 담당 부처를 뒤섞지 않는다.
- 법령명(공공기관의 운영에 관한 법률 / 지방공기업법)을 정확히 쓴다.

## 문서

- 강의계획, 원고, 슬라이드 메모를 섞지 않는다. `강의계획서.md`(정본) / `docs/`(원고) / `lecture/`(파생)로 분리한다.
- 외부 사례·해외 제도의 최신 사양은 확인 없이 단정하지 않는다.
- 문체: 쉬운 설명은 유지하되 지나치게 구어적 표현(뜯어보기, 굴리다, 줄 세우다, 셈이다, 뒷전, 종이 위의 점수, 의문형 헤딩)은 쓰지 않는다. 헤딩은 명사구로. (첫 초안부터 적용)
- 기존 `강의계획서.md`는 요청 범위 안에서만 수정한다.
