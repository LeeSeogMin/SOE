# Gotchas

## General

- 출처 없이 수치·지표·부처명·법령을 본문에 쓰지 않는다.
- 본문 사실은 `content/research/ch{N}-sources.md`에서 확인된 것만 인용한다.
- 요청 범위 밖의 원고 전면 개편이나 파일명 변경은 하지 않는다.

## This Project

- 부처명: 공공기관 경영평가·공공기관운영위원회는 재정경제부 소관(2026-01 개편). "기획재정부"로 쓰지 않는다.
- 편람 배점·지표는 2026년도 판 기준. 이전 연도 값과 섞지 않는다.
- 재무 수치(부채·적자·요금)는 결산·경영공시로 확인하고 기준 시점을 밝힌다.
- 기관 유형 구분(공기업/준정부기관/기타공공기관, 지방공사/공단/직영기업)을 혼동하지 않는다.
- OECD·해외 사례를 한국 맥락 근거로 과장하지 않는다. 적용 자격을 표기한다.
- 이 프로젝트는 실행 코드가 없다. 코드 실행 로그·evidence JSON 게이트를 도입하지 않는다.
